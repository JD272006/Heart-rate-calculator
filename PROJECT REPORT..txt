2. Introduction


 The heart rate calculator is a simple python based command line project that calculates a person's heart rate in beats per minute(BPM)

The user enters the values to number of beats and time taken to measures those beats.
the program then calculate the heart rate using mathematical formula.



3. Objective

the main objective of the project

. to calculate the BPM
. to implement a simple mathematical formula using python.
. to create project using that can be executed directly from the command line.



4. Technologies used

programming language : python
interface: command line/ terminal



5. Formula used

the heart rate calculation:
BPM = ( no. beats / time in seconds)*60



6. Working of the project

The program works in the following steps:

. The program starts.
. The user enter the name.
. The user enters the number of heart beats.
. The user enters the measurement time in seconds.
. The program applies the BPM formula.
. The calculated heart rate is displayed on the screen
