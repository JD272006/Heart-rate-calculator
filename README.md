# Heart-rate-calculator

A simple Python program that calculates your heart beat rate (BPM) based on the number of beats and the time in second.

## Requirements

* Python 3.x

## How to Run
1.Install Python 3.x.
2.Download or clone the project.
3.Open a terminal in the project folder.
4.Run:
python heart_rate_calculator.py
5.Enter the number of heart beats and the measured time when prompted.

## Formula

**BPM = (Number of Beats / Time in Seconds) × 60**

## Note

This project is for educational purposes and should not be used as a medical diagnostic tool.
